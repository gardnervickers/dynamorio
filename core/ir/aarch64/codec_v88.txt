# This file defines instruction encodings for v8.8 instructions.

# See header comments in codec_v80.txt and opnd_defs.txt to understand how
# instructions are defined for the purposes of decode and encode code
# generation.

# Notes on specific instructions:
#
# CPY*, CPYF*, SET* (FEAT_MOPS)
# -----------------------------
# Each memory copy or set is a prologue (P), main (M) and epilogue (E)
# instruction, run in that order. All three update their registers to say
# how far the operation has got. The prologue writes NZCV with the algorithm
# option the implementation chose, and the main and epilogue instructions read
# it back.
#
# The mops_cpy and mops_set opndsets in codec.c decode the encodings with
# overlapping registers, or with register number 31 other than as the SET*
# data register, as OP_xx: these are CONSTRAINED UNPREDICTABLE
# (Unpredictable_MOPSOVERLAP31) and may be UNDEFINED.
#
# Only the forms without options are defined here. The unprivileged (T),
# non-temporal (N) and tag-setting (SETG*) forms still decode as OP_xx.

# Instruction definitions:
